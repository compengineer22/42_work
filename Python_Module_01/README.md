

#  Code Cultivation

## Project Objective

This project introduces **Object-Oriented Programming (OOP) in Python** by building a digital garden system.

It focuses on:

* Class design
* Encapsulation

* Inheritance
* Method types (instance / class / static)
* Code organization and scalability

---

## ⚙️ Compilation & Usage

Each exercise is an independent Python file.

Run:

```bash
python3 <file>.py
```

Example:

```bash
python3 ex0/ft_garden_intro.py
```

## 📚 Mandatory Concepts (VERY IMPORTANT FOR EVAL)

### 🔹 Exercise 0

* Program execution entry point
* `if __name__ == "__main__"`
* Basic variables and printing

👉 You MUST explain:

* Why `__name__ == "__main__"` is used
* Difference between script execution and import

---

### 🔹 Exercise 1

* First **class implementation**
* Attributes: name, height, age
* Instance method: `show()`

👉 You MUST explain:

* What is a class
* What is an instance
* Why we use classes instead of variables

---

### 🔹 Exercise 2

* Methods modifying object state (`grow()`, `age()`)
* Object evolution over time

👉 You MUST explain:

* Difference between attributes and methods
* How objects store state

---

### 🔹 Exercise 3

* Constructor (`__init__`)
* Object initialization

👉 You MUST explain:

* Role of `__init__`
* Why constructors improve design

---

### 🔹 Exercise 4

* **Encapsulation**
* Getters / Setters
* Data protection

👉 You MUST explain:

* Why direct access is dangerous
* Protected attributes (`_attribute`)
* Validation logic

---

### 🔹 Exercise 5

* **Inheritance**
* `super()` usage
* Method overriding

👉 You MUST explain:

* Parent vs child class
* Code reuse
* Method overriding vs extending

---

### 🔹 Exercise 6

* **Advanced OOP**

  * `@staticmethod`
  * `@classmethod`
* Nested class (statistics system)
* Global function outside classes

👉 You MUST explain:

* Difference between static / class / instance methods
* Why use a nested class
* How statistics are tracked

## 🧪 Evaluation Tips

During defense, you may be asked to:

* Modify your classes
* Add new features

## ❗ Common Mistakes (Avoid These)

* ❌ Not understanding `__init__`
* ❌ Copy-paste OOP without understanding
* ❌ Wrong use of `super()`
* ❌ No real encapsulation
* ❌ Confusing static/class methods
* ❌ Repeating code instead of inheritance
