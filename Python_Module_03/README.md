## Exercises
### ex0 - ft_command_quest
Introduction to:

* sys.argv
* Lists
* Command-line arguments
Displays all arguments received by the program.

Run:

```bash
python3 ft_command_quest.py hello world
```
### ex1 - ft_score_analytics
Introduction to:

* Lists
* Exception handling
* Numeric processing

Processes scores and calculates:

* Average
* Maximum
* Minimum
* Range

Run:

```bash
python3 ft_score_analytics.py 1500 2300 1800
```
---
### ex2 - ft_coordinate_system

Introduction to:

* Tuples
* User input
* Mathematical calculations

Stores and manipulates 3D coordinates.

Run:

```bash
python3 ft_coordinate_system.py
---
### ex3 - ft_achievement_tracker
Introduction to:

* Sets
* Set operations
* Random generation

Analyzes player achievements using:

* union
* intersection
* difference

Run:

```bash
python3 ft_achievement_tracker.py
```
---

### ex4 - ft_inventory_system

Introduction to:

* Dictionaries
* Parsing
* Inventory analysis

Creates an RPG inventory system from command-line parameters.

Run:

```bash
python3 ft_inventory_system.py sword:1 potion:5 shield:2
```
### ex5 - ft_data_stream
Introduction to:

* Generators
* yield
* Lazy evaluation

Creates endless game event streams.

Run:

```bash
python3 ft_data_stream.py
```

### ex6 - ft_data_alchemist
Introduction to:

* List comprehensions
* Dictionary comprehensions
* Data filtering

Transforms and filters player data efficiently.

Run:

```bash
python3 ft_data_alchemist.py
```
