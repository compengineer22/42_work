# 🌱 Growing Code

## 📌 Description

This project is an introduction to Python programming through simple exercises based on garden data.

It focuses on fundamental concepts such as:

* input / output
* variables
* conditions
* loops
* functions
* recursion
* type annotations

---

## ⚙️ Requirements

* Python **3.10+**
* Respect **flake8** norms
* Each file must contain **only one function**
* No `main` function
* No code outside the required function

---

## 📁 Structure

```
ex0/  ft_hello_garden.py
ex1/  ft_garden_name.py
ex2/  ft_plot_area.py
ex3/  ft_harvest_total.py
ex4/  ft_plant_age.py
ex5/  ft_water_reminder.py
ex6/  ft_count_harvest_iterative.py
      ft_count_harvest_recursive.py
ex7/  ft_seed_inventory.py
```

---

## 🧪 Usage

A helper file `main.py` is provided.

Run:

```bash
python3 main.py
```
